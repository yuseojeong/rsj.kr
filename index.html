쏙

함께 저장하고 찾아볼 수 있는 그룹 아카이빙 앱

문제

단톡방과 SNS에 모은 링크는 대화에 묻혀 다시 찾기 어려웠습니다. 저장한 정보가 실제 활용으로 이어지도록 재탐색과 공동 활용의 불편을 풀고자 했습니다.

판단

50명 설문과 유저저니에서 저장 위치가 흩어지는 문제를 확인했습니다. 함께 모으는 파일과 카테고리, 다시 찾기 위한 검색·핀 기능을 연결하는 방향으로 MVP를 정했습니다.

실행

저장 화면의 필수 입력과 선택 입력을 나누고, 유저플로우·화면설계서를 작성했습니다. 개발 중 드러난 예외는 조건별 플로우차트로 보완하고 A/B 테스트로 UI를 개선했습니다.

담당 업무 자세히 보기＋

요구사항 분석 및 프로젝트 범위 정의

  • 50명 대상 사용자 조사로 링크 재탐색·그룹 공유 과정의 문제 파악
  • 조사 결과를 페르소나·유저저니맵으로 구조화, 디자인·개발팀 의사결정 기준 수립
  • 핵심 사용자 흐름에 따른 저장·분류·탐색 중심 MVP 범위 및 구현 우선순위 정의

화면·정책 및 산출물 관리

  • Figma 기반 E2E 유저플로우·화면설계서 작성
  • UI 요소별 인터랙션·입력 조건·조건 분기·예외 케이스 상세 정의
  • 기능 변경 날짜·이유·영향 범위 문서화, Jira 기반 일정·화면별 진행 상황 관리

협업 및 사용성 개선

  • 개발자·디자이너와 기능 범위·구현 우선순위·일정 조율
  • 사용성 가설 검증을 위한 A/B 테스트 설계 및 2차 테스트 진행
  • UI 개선 후 평균 과업 수행 시간 44% 단축·미스클릭률 23% 감소
결과

MVP 출시와 UI 개선을 거쳐 저장 과업 시간은 평균 44% 단축, 미스클릭률은 23% 감소했습니다.

회고

정상 흐름만으로는 개발 중 생기는 질문을 줄이지 못했습니다. 다시 한다면 개발 전에 예외와 조건 분기를 함께 정의하고, 변경 이유와 이력까지 공유하겠습니다.

koach

관계와 상황에 맞게 배우는 AI 한국어 회화

문제

단어와 문법을 알아도, 상대와의 관계에 따라 달라지는 예의·격식과 일상 표현을 실제 대화에서 익히기는 어려웠습니다. 교재에서 배운 한국어와 실제 한국인과의 대화 사이의 간극을 줄이고자 했습니다.

판단

한국어 학습자 17명의 설문에서 관계·상황에 맞는 표현과 실생활 대화에 대한 수요를 확인했습니다. 한국 사회·정서 문화를 학습한 챗봇과 대화하며 배우는 방식을 기획하고, 친밀도 설정과 맥락에 맞는 교정을 연결했습니다.

실행

관계별 채팅방, 거리감 슬라이더, 교정·표현 저장 흐름을 구체화했습니다. 멀티 에이전트 구조와 데이터 흐름을 설계하고, 출시 후에는 GA4 분석을 바탕으로 온보딩·채팅 진입과 답변 품질을 개선했습니다.

담당 업무 자세히 보기＋

사용자 행동 분석 및 서비스 개선

  • GA4 이벤트·서비스 지표 설계, 회원가입·채팅 진입·첫 응답 이후 이탈 흐름 분석
  • 온보딩 개편으로 회원가입 전환율 11.2% → 16.0%, 4.8%p 개선에 기여
  • 앱 전환 유도·리텐션 푸시 설계로 채팅 전환율 18.5% → 42.5%, 24.0%p 개선에 기여

화면·정책 설계 및 AI 품질 개선

  • Figma 기반 IA별 화면설계서 작성, 화면 동작·서비스 정책·예외 케이스 구체화
  • 관계·상황별 대화 및 교정을 위한 멀티 에이전트 구조·데이터 흐름 설계와 문서화
  • RAG 기반 품질 개선으로 첫 응답 이탈률 62.1% → 20.0%, 42.1%p 감소에 기여

협업 및 서비스 운영

  • WBS 기반 작업 범위·일정 관리 및 개발·디자인 구현 우선순위 조율
  • 리텐션·사용자 행동 분석을 위한 이벤트·지표 설계 및 데이터 적재 가이드 작성
  • 로그 조회·문의 처리 흐름의 어드민 표준화로 반복 운영 업무 정리
  • 서비스 기획·운영 참여 — 사전 예약 2주간 354명 모집·사용자 282명 획득
결과

온보딩 개편 후 가입 전환율은 11.2% → 16.0%, 앱 전환 유도·푸시 설계 후 채팅 전환율은 18.5% → 42.5%로 높아졌습니다. RAG 기반 개선 후 첫 응답 이탈률은 62.1% → 20.0%로 줄었습니다.

회고

행동 데이터로 가설을 검증하는 방식과, 구조를 먼저 공유하는 기획의 중요성을 배웠습니다. 에이전트와 데이터 흐름을 시각화하니 개발·기획 간 소통이 원활해졌습니다.

연OX

연애 고민을 나누는 익명 OX 투표 커뮤니티

문제

반복되는 연애 고민을 친구에게 다시 꺼내기 부담스러워 혼자 감당하는 경우에 주목했습니다. 신원을 드러내지 않고 다른 사람의 관점을 얻는 공간을 만들고자 했습니다.

판단

익명 사연과 OX 투표로 가볍게 의견을 나누도록 설계했습니다. 모바일에서의 동선은 정적인 화면만으로 확인하기 어려워, 와이어프레임을 코드로 구현해 직접 조작하며 검증했습니다.

실행

투표·댓글·익명 표시 정책을 정의하고 AI와 함께 화면을 구현했습니다. 코드 구조가 일관되지 않는 문제에는 AGENTS.md로 개발 규칙을 세우고, OX 추천을 조정할 프롬프트·테스트 어드민을 만들었습니다.

담당 업무 자세히 보기＋

요구사항 및 참여 정책 설계

  • 초기 기능 요구사항 정의 및 사연 작성 → 투표 → 댓글 → 후기 요청 흐름 설계
  • 한 사용자·한 글당 1회 투표, 투표 후 댓글 조회·작성 정책 정의
  • 게시글 내 동일 작성자의 익명 번호 유지 규칙 설계

AI 기반 프로토타이핑 및 개발 규칙

  • React Native·Expo 프로토타입 구현, 모바일 직접 조작을 통한 화면·동선 개선
  • AGENTS.md 개발 규칙 작성, 화면 컴포넌트·사용자 행동·데이터 통신의 역할별 구조화

프롬프트 및 운영 도구 제작

  • 상황별 Few-shot 예시를 활용한 사연 맥락 기반 O/X 선택지 생성 프롬프트 설계
  • 프롬프트 수정·저장·테스트를 통합한 운영 어드민 AI 기반 제작
  • 게시글 검수 기준·응답 형식 정의 및 마케팅 콘텐츠 준비
결과

모바일 화면과 프롬프트 수정·저장·테스트용 어드민을 구현하고 마케팅 콘텐츠 5종을 제작했습니다. 현재 마케팅 준비 단계로, 실제 사용자 반응은 아직 검증 전입니다.

회고

AI에도 요구사항뿐 아니라 코드 구조와 검수 기준이 필요했습니다. 화면 구현 다음에는 실제 유입 후 참여와 재방문 가설을 검증하는 일이 남아 있습니다.
